# InsTX-Life21 — Simulador de seguros de vida

Aplicación estática HTML/CSS/JavaScript para practicar el examen de agente de seguros de vida de Texas.

## Contenido
- Examen de 100 preguntas por intento, con orden aleatorio.
- Cada intento incluye 15 preguntas garantizadas sobre ética y conducta del productor y 85 preguntas aleatorias de otros temas.
- Casos de uso, cuatro opciones, una mejor respuesta y explicaciones al revisar.
- Tipos de pólizas, endosos, disposiciones, solicitudes, suscripción, grupo, anualidades, impuestos básicos, ética y leyes de Texas.

## Publicar en Vercel
1. Sube `index.html` y `README.md` a la raíz de un repositorio GitHub.
2. Importa el repositorio en Vercel.
3. Selecciona `Other` si pregunta framework.
4. No uses comando de build; el directorio de salida es la raíz (`.`).
5. Pulsa Deploy.

## Nota de estudio
Este proyecto es material de práctica independiente, no un examen oficial ni asesoría legal. Las preguntas sobre ley de Texas son educativas; verifica plazos, excepciones y requisitos actuales en el esquema de Pearson VUE y en el Texas Insurance Code.

Referencias oficiales: Texas Insurance Code Chapter 541 (prácticas injustas o engañosas): https://statutes.capitol.texas.gov/GetStatute.aspx?Code=IN&Value=541
